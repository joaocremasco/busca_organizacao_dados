# Overlay de alterações do Projeto 1

Os arquivos deste pacote preservam os caminhos relativos do projeto. Copie o
conteúdo para a raiz do repositório correspondente, substituindo os arquivos
existentes quando solicitado.

## Incluídos

- Correções em `src/item.c`, `src/collection.c`, `src/export.c` e nas estruturas cruzada e ordenada.
- Revisões de comentários nos headers em `include/` e `data_structures/include/`.
- `tests/test_tads.c` e alvo `make test` no `Makefile`.
- Relatórios e README revisados, script e PDFs das figuras, dados brutos atualizados e exemplos medidos.
- `relatorio_latex_projeto.pdf`, PDF presente no diretório de trabalho ao montar este overlay.

Não inclui datasets, binários, arquivos objeto, arquivos `.d` nem o ZIP de entrega. O `games.csv` continua sendo necessário para executar os exemplos de jogos.
